# Team Accountability & Operating Rhythm

## 1. Principles
- Every recurring process has one accountable owner.
- Tasks have clear outcomes, due dates and status.
- Handover notes capture current state, next action and unresolved risk.
- Escalations include impact, urgency, evidence and requested decision.
- Performance conversations use agreed measures and documented examples.

## 2. Responsibility matrix (RACI)
**R = Responsible, A = Accountable, C = Consulted, I = Informed**

| Activity | Operations Lead | Vendor Ops | Dispatch | Support | Product / Tech |
|---|---|---|---|---|---|
| Order workflow ownership | A | R | C | C | C |
| Vendor onboarding and guidance | A | R | I | I | C |
| Rider assignment process | A | C | R | I | C |
| Customer complaint logging | A | I | C | R | C |
| System defect escalation | C | I | I | R | A/R |
| KPI reporting | A/R | C | C | C | C |
| SOP review | A/R | C | C | C | C |

## 3. Operating rhythm
| Touchpoint | Cadence | Purpose | Output |
|---|---|---|---|
| Shift handover | Every shift | Open orders, exceptions and staffing | Handover log |
| Daily operations review | Daily | Service exceptions and urgent blockers | Action list |
| Vendor performance review | Weekly | Trends, recurring issues and coaching | Vendor actions |
| Cross-functional review | Weekly | Dependencies, product/system issues | Decisions and owners |
| KPI review | Monthly | Trends, root causes and improvement priorities | Improvement plan |

## 5. Escalation
Escalate immediately where there is a material safety, privacy, security, financial or service-continuity concern. For routine service delays, follow the approved response window and escalation chain. Record the time, facts, impact, action taken and decision owner.
